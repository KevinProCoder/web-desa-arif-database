SEMParuk Sutera — Website Profil & Promosi
=============================================

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Internet diperlukan untuk font Google dan peta OpenStreetMap/Leaflet.

Folder:
- index.html
- css/style.css
- js/script.js
- assets/images/

Penting:
- File SVG di assets/images/ adalah placeholder lokal. Ganti dengan foto asli (JPG/PNG) dan ubah nama file pada HTML/JS jika diperlukan.
- Statistik masih berupa template. Isi data resmi pada atribut data-target di index.html.
- Peta menggunakan titik referensi 1.1829, 109.0723 sesuai gambar yang diberikan. Jika koordinat resmi berbeda, ubah latitude/longitude di js/script.js dan teks koordinat di index.html.
